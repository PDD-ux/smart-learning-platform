# 文豪智能学习平台 · 当前三主线演示

更新：2026-10-20。此页只写当前可用产品路径；2026-10-17 的全功能手册是历史记录，其中试卷、组卷、XP 主线和 OpenAI 型号不再用于本次演示。

## 先打开

根目录只保留三个双击入口：`启动演示.cmd`用于打开已有资料和网页（等价于`npm run demo:start`）；`启动云端推理演示.cmd`用于Notebook已运行时现场新导入视频；`启动人脸服务.cmd`仅在人脸登录演示前另开。先确保本机PostgreSQL可用；本地演示使用memory队列，无须为了旧脚本额外启动Redis。只读体检改在终端运行`npm run demo:check`，新导入前运行`npm run demo:check -- --import`；停止人脸服务运行`npm run face:stop`。不要同时启动普通与云端两个网页入口占用3000端口。

保留启动窗口，在浏览器打开 <http://127.0.0.1:3000/>。首页可免登录预览工作台；真正的资料、班级和批改数据需要登录。不要用 `demo:prepare` 重设已有账号密码；直接使用本人现有账号。

## 建议演示顺序

1. **资料学习与智能笔记**：学员登录后从工作台进入“学习中心”，打开已有视频，演示播放、随时间定位的笔记与来源回看。导入面板可选择本人的书籍文件，或预览公开文章/直接 PDF 链接，确认后在阅读页选章、摘录、书签、续读与导出。专题问答前要先提取**真正包含正文的章节**：部分网页的第一章仅含标题/页脚，不能用其“已就绪”状态代替正文覆盖。示例预览不能当作本人真实学习记录。
2. **班级课程与作业**：班级负责人用管理员账号进入“班级课程”，创建班级并发布章节、任务和截止时间；学员通过邀请码加入，先存草稿，再正式提交；负责人退回并写评语，学员补充后重新提交，负责人给出正式批阅。提交状态和版本在各自页面核对。
3. **智能批改与错因订正**：学员从“智能批改”导入本人文字/PDF或选择本人允许处理的正式提交，先人工核对题目、答案及参考依据，再明确同意调用星火 Lite 查看建议和错因；订正后看前后记录。AI建议不等于班级正式成绩，依据不足会显示待核验。

## 现场重新导入视频

1. 在华为云确认原Notebook处于运行中，在桌面主仓库启动已保存的限时推理控制器，等其状态显示`ready`；另开终端运行`npm run demo:check -- --import`。这次限时进程启动于北京时间2026-10-20 19:45，默认约20:45停服务、隧道和网页，不会替你停止收费的Notebook。
2. 用本人账号打开 <http://127.0.0.1:3000/import>，选择自己有权使用的短视频并点击开始导入。**必须在学习中心出现一条本次新增资料**，且状态从处理中转为“已就绪”；看到旧视频的“已就绪”不算新导入通过。
3. 打开新资料学习页，核对视频能播放、出现本次内容相关的转写/画面文字、笔记的时间引用能回跳；再写一条本人笔记并刷新，确认仍可看到。若失败，保留页面错误与发生的步骤，不重复创建同名资料。
4. 演示结束后在华为云控制台手动停止Notebook，避免继续计费。下次重启Notebook时重新核对SSH主机指纹与控制器`ready`状态。

## 现场边界

- 已解析的本地资料可在华为云 Notebook 关闭时展示；**现场新视频**的关键帧与 OCR 需先启动原 ModelArts Notebook 和推理转发，再运行 `npm run demo:check -- --import`。不要把健康检查当作新视频已处理成功。
- 本机 CPU 人脸服务可独立启动；本人实际摄像头登录仍需现场确认。密码登录可正常使用，之后手动打卡。
- 目前已通过生产构建、全量单元测试和分段真实接口演练；三角色在原生桌面/窄屏页面上的整条连续流程尚未核销。现场发现异常时保存错误状态，不用示例数据冒充真实结果。详细证据见 [§29.11 阶段验收](../acceptance/three-core-20261020.md)。
