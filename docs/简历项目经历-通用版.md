## 项目一：基于机器视觉的智能交通沙盘车辆违规掉头检测系统

**项目背景**：依托华为智慧交通沙盘与 M2241 智能摄像设备，实现实景沙盘下车辆实线违规掉头的自动识别与抓拍。

- **数据集构建**：使用 Python 抽帧清洗 + LabelImg 标注，按 VOC 格式规范构建高质量训练 / 验证集。
- **模型训练与优化**：基于 YOLOv5 在 GPU 集群完成训练与精度验证，经多轮调参将检测准确率提升至 **92%**。
- **模型转换与端侧部署**：独立完成 PT→ONNX→Caffe→WK 四级转换，适配华为 M2241 嵌入式架构，使用 RuyiStudio 完成量化编译。
- **实景落地验证**：通过 MobaXterm / FTP 部署至摄像头，在沙盘实景下实现实时推理抓拍，系统稳定运行，误报率控制在 **3% 以内**。

## 项目二：智能面试智能体（AI Mock Interview Agent）

**项目背景**：针对应届生缺乏面试实战演练的痛点，基于大模型开发可模拟真实面试场景的智能体。

- **需求分析与产品设计**：梳理技术 / 行为 / 情境三类面试题型，设计多轮对话流程与评估维度，定义 Agent 角色设定与应答逻辑。
- **技术选型与开发**：基于 LangChain + ChatGLM / DeepSeek 搭建 Agent，通过 Prompt Engineering 设计角色提示词与动态追问机制。
- **功能实现与部署**：实现岗位定制化题目、实时交互追问与评估报告；基于 FastAPI + Web 联调，组织 **20 余名同学**内测并迭代优化。
- **工程效率实践**：运用 AI 编程工作流（Agentic Coding，代码生成与自动化多轮迭代）辅助 Agent 与 Web 端开发，提升功能交付与缺陷修复效率。

## 项目三：基于 YOLOv8 的智慧教室课堂行为分析系统

**项目背景**：针对课堂专注度难以量化的问题，设计并实现面向智慧教室的学生行为实时分析系统。

- **数据集构建**：采集课堂场景图像并以 LabelImg 标注趴桌、举手、玩手机、站立四类行为，构建约 **5000 张**训练集。
- **模型训练与评估**：基于 YOLOv8 完成训练与多轮调参，mAP@0.5 达 **91%**，单帧推理满足课堂实时分析需求。
- **系统落地**：实现抬头率统计、行为分布看板与专注度报表，基于 OpenCV + Flask 接入教室摄像头完成实时推理演示。

## 项目四：智能学习平台

**项目背景**：端云协同的智能学习平台（云侧 MindSpore 模型服务 + 讯飞星火大模型，端侧 Web 应用），面向个人与教学场景提供 AI 辅助学习。

- **技术架构**：采用 Next.js 14（App Router）+ React 18 + TypeScript（严格模式）+ Tailwind CSS 构建前端，Prisma + PostgreSQL 持久化，端云协同调用 MindSpore 模型服务与讯飞星火大模型。
- **核心功能开发**：实现基于 SM-2 算法的间隔重复闪卡复习、掌握度动态计算、AI 理解生成流水线（异步任务编排调用 ASR / 大模型）、学习笔记 AI 摘要与问答、知识图谱概览、学习计划与题库等模块。
- **工程实践**：落地 JWT + httpOnly Cookie 鉴权与资源归属校验、接口限流防护、管理员后台与考勤（人脸 / 挑战）等功能；编写 PRD / 设计 / 架构 / 数据模型规范文档保障多人协作一致性。
