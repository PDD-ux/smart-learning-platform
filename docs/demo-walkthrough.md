## 启动与已有资料展示

1. 双击桌面主仓库的“启动演示.cmd”，保持终端运行。也可在仓库执行 `npm run demo:start`。
2. 浏览器统一使用 `http://127.0.0.1:3000/login`，用本人学习者账号登录；不要在localhost与127.0.0.1之间反复切换。
3. 学习中心打开已有30分钟视频，先关闭随播放AI整理，再播放、查看预解析重点、点击已有引用回看、保存个人笔记。复习中心可展示先回忆、查看要点、自评；实际提交评分会保存学习记录。
4. 题库展示已有题目及作答入口，学习计划展示已有安排。管理员使用自己的管理员账号进入 `/admin`，不会因学习者登录而自动取得权限。

只展示已有解析内容不需要启动云端视觉推理；若现场重新导入视频或演示云视觉推理，需要另外确认相应服务可用。人脸服务已恢复；停止时使用密码登录和普通打卡，模型健康不代表本人摄像头验收。随播放AI整理仍需在线大模型。

## 学习计划演示
