## 按顺序展示

1. 在工作台介绍学习资产、待复习内容及薄弱点。密码登录后可手动普通打卡；打卡不代表实际学习时长。
2. 进入[学习中心](http://localhost:3000/import)，展示资料导入和解析状态。可以选本人获授权的小图片展示新导入；30分钟整段新导入已在10:37完整验收通过，现场不必等待十多分钟，可展示下方真实记录。
3. 打开[原30分钟视频](http://localhost:3000/study/cmuqhyf7h00027q29tijy4uer?t=247)，播放视频，展示同步重点、当前位置转写、AI整理笔记和个人笔记。选择一个已有重点的时间链接回看；现场补充笔记由本人输入和保存。原资料保持原5知识点/17定位；本轮隔离验收的11点已清理，不把它们说成原页面的数量。
4. 进入[今日复习](http://localhost:3000/review)，翻面查看答案，按自己的真实掌握程度评分；评分会更新复习记录和掌握度。进入[练习题库](http://localhost:3000/question-bank)展示已有题目、作答与解析，没有题时明确展示空状态或由本人发起生成。
5. 进入[知识图谱](http://localhost:3000/graph)，展示节点和薄弱点；没有关系或薄弱点时不宣称已有丰富关联。
6. 进入[AI学习助手](http://localhost:3000/assistant)，选择本人已理解完成的资料，提出与资料相关的问题，并检查引用、点击返回来源。问答实际调用模型，网络或输出校验失败时应展示明确状态。
7. 进入[学习计划](http://localhost:3000/study-plans)，展示目标、提醒及完成状态。最后由本人退出学习者账号并以管理员账号进入[管理员中心](http://localhost:3000/admin)，展示总览、用户管理和签到查询；签到记录只读。密码不写入操作单。

人脸登录可作为额外展示，先按DEPLOY.md §8.6检查独立服务并由本人主动授权/操作摄像头；本轮未启动或复验人脸服务，不列为本次已通过项。scan是便捷身份匹配，不能宣称专业活体防伪。
