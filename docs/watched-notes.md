# 已导入视频：边看边生成笔记

从学习中心打开已解析视频，播放器旁是“边看边生成笔记”。播放后约30秒，系统把本次连续看过且完整结束的转写片段送到星火整理，笔记会逐段累积；暂停/播放结束会整理已看尾段。不是麦克风录音，不需要权限，也不重新运行ASR。

“随播放AI整理”开关可关闭，开启会消耗现有星火额度。拖动跳过的部分不生成，本次先前已看的待处理来源仍保留。段落跨过当前播放位置时，会等完整看完后再处理。模型失败停止自动请求，点击手动重试；不切其它模型。本页最多60批、每批12段/6000字，长片段超限不截断冒充完整。

每段可以核对原文/点击时间回看、保存到“我的笔记”；保存按钮成功才表示已入库。也能导出本次Markdown。未保存笔记暂存在本页，刷新/离开会丢失；导出仅覆盖已成功整理的本次来源，不等于完整课程总结。

新批次采用“AI精选原文”：AI只挑选来源编号，标题为服务端固定的“原文要点N”，正文由服务端引用所选编号之间的连续转写和相邻片段，不自由改写否定或条件。ASR转写仍可能出错，跨批上下文也可能不足；请结合视频核对。旧批次标明“历史AI摘要 · 未按原文摘录规则核验”，既有正文不自动覆盖。新保存笔记标明“原文摘录，转写待核对”。模型格式失败显示中文提示，不展示英文校验细节。

原“预解析重点与个人补充”在可展开区域；下方完整AI笔记仍保留。独立麦克风菜单已撤下，旧/live-notes跳转学习中心；历史迁移不做破坏性回滚。
