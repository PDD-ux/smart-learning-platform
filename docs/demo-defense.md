# 毕设演示操作单与讲稿

更新：2026-10-15，§26.3。本机演示以此单为准，旧demo-walkthrough/demo-local中的数量和健康状态是历史记录。建议主线8–10分钟，在线AI另留1–2分钟；不保证现场API响应时间。

## 启动和准备

在桌面主仓库双击“启动演示.cmd”，或执行：

```powershell
Set-Location 'C:\Users\qwh76\Desktop\智能学习平台'
npm run demo:check
npm run demo:start
```

统一打开 [登录页](http://127.0.0.1:3000/login)，用本人学习者账号登录，保持网页终端运行。3000已有文豪网页时启动器会复用；未确认占用者时不会停止其它程序。预检只读，`configured`不证明模型余额/真实调用成功。

演示前完成 [录屏与交付检查单](demo-checklist.md)，备份见 [本地备份与恢复](demo-backup-restore.md)。入口找不到时使用顶栏“帮助”或 [使用指南](http://127.0.0.1:3000/help)。

本次三份固定资料均READY/COMPLETED：30分钟视频5点/5张复习卡/5道已有题，30秒视频1点1卡，图文资料2点2卡。这些是原账号私有资料，新账号不会自动看到，不要改归属或公开来填补空列表。数量是当日快照，不是演示必须造出的数字。

## 学习者主线（约6分钟）

### 1. 工作台与学习中心（1分钟）

讲：“平台把资料、笔记、练习、复习和计划连接起来。统计来自当前账号，不同用户数据独立。”

展示继续学习与今日任务，进入 [学习中心](http://127.0.0.1:3000/import)的个人资料。导入与已有资料在同一入口，不必每次上传。密码登录可普通打卡；打卡不表示实际学习时长，也不自动增加XP。

### 2. 看课、笔记和回看（2分钟）

打开本人 [30分钟视频](http://127.0.0.1:3000/study/cmuqhyf7h00027q29tijy4uer?t=247)。**播放前先取消“随播放AI整理（会使用API额度）”**，使主线不依赖在线模型。点击“预解析重点”查看已有结果，点击时间引用回到真实位置。在“我的笔记”保存一句本人补充，再到 [我的笔记](http://127.0.0.1:3000/notes)搜索、回看或导出。

讲：“完整AI笔记提前解析；随看笔记按本次看过的转写逐段生成；个人笔记独立保存，支持回到来源。”

旧产物没有因26.2更新自动改写，仍需核对。不要把原完整笔记冒充刚刚实时生成。未保存的随看草稿离页前必须保存或导出。

### 3. 练习、复习与图谱（2分钟）

[练习题库](http://127.0.0.1:3000/question-bank)筛选同一视频，使用已有题，展示作答、解析、来源和本轮总结；确有本轮错题再使用“只重练本轮错题”。不改答案/成绩凑效果，不把订正后正确率说成原始成绩。现场不必点击生成题目。

[复习巩固](http://127.0.0.1:3000/review)先回忆、再看要点、真实自评。无到期项时展示空态和下一步，不改日期或数据库造到期卡。自评影响排期，不等于客观考试得分；文档新卡片是有来源的原文回忆。

[知识图谱](http://127.0.0.1:3000/graph)筛选资料、选具体节点，展示实际关系、来源与对应练习。无记录与已证明薄弱分别说明，没有关系不声称生成了丰富关系。

### 4. 计划与助手（1分钟）

[学习计划](http://127.0.0.1:3000/study-plans)创建本人演示安排，提醒时间不晚于学习时间；展示完成/撤销。勾选完成只代表本人确认目标，不证明实际学满目标分钟数，不自动发XP。

[AI学习助手](http://127.0.0.1:3000/assistant)选择本人同份资料、预算和目标，可只展示待发送草稿；发送才调用模型，方案确认保存才进入计划。当前`AGENT_REVIEW_READY=false`，使用安全原文证据模式，不说已经通过自由解释/自主教学验收，不自动代答或保存方案。

## 管理员端（约2分钟）

先保存草稿并退出学习者账号，再以本人管理员密码登录 [管理中心](http://127.0.0.1:3000/admin)。导航独立，学习者换地址不能获得管理权限。

1. “管理总览”：刷新真实用户、角色与当日签到概况。
2. “用户管理”：搜索/分页/查看角色。需演示新增/编辑/删除时，仅新建明确的临时演示账号、修改昵称后确认删除它，不删除自己或已有用户，不录制密码输入。
3. “签到记录”：筛选日期/账号，管理员只看签到结果，不看人脸照片、特征或他人私人学习内容。
4. “共享课程”和“讨论与举报”：目前正式交流开关关闭，没有指定可正式发布的授权素材。展示入口和说明；评论闭环使用 [双用户及管理员验收记录](acceptance/phase25-reacceptance-20261015.md)说明已用自建隔离素材跑通提问→回复→消息→举报处理。空列表和未开放说明不伪装成现场已有评论。

正式互动演示须先选管理员本人自建或明确获传播授权素材，准备独立副本、预览确认，再单独安排开放。本文不改开关、不发布原三份资料。共享只读课程与个人题库/成绩分属不同空间。

## 可选在线分支：只选一个

### A. 已导入视频边看边记

主动勾选“随播放AI整理”，连续看约30秒并等完整转写片段结束；暂停可整理已看尾段。展示新生成一批、原文/时间核对、显式保存。拖动跳过部分不会假装看过。讲：“AI挑选已看来源，服务器保留原文摘录；不采麦克风，不是逐字零延迟，ASR文字仍需核对。”

失败后自动请求停止、保留已生成结果，可手动重试一次或关闭开关继续播放/手动记笔记；不连续点击或换供应商。本页最多60批，不能把一段成功说成30分钟连续生成验收。详见 [随看笔记](watched-notes.md)。

### B. 短文档导入

可交付素材使用自编 [梯度下降讲义](demo/梯度下降演示讲义.md)，从学习中心“文档导入”上传。该讲义本轮未发模型，不承诺固定点数/耗时。本机历史三页PDF在`.taskbook-working/pdf-positive-20261013/first-three-pages.pdf`，仅用于个人学习验收，不随源码分发，不代表有公开传播许可；缺失时不拿222页整份替代现场演示。

等待解析和理解完成后看原文、知识点、笔记、回忆卡及引用。26.2真实三页导入及同份助手请求约33秒、4点4卡是历史测量，不保证下次相同。新文档由AI选事实编号，服务器恢复原文/标题/来源；卡片是原文回忆自测，不冒充语义推理测验。资料不足应明确拒绝，不能取消校验造结果。

只复现技术通路可用源码入口（新输出目录、输入也须在忽略目录）：

```powershell
npx tsx scripts/acceptance/pdf-positive-smoke.ts .taskbook-working/pdf-replay-新时间 .taskbook-working/pdf-positive-20261013/first-three-pages.pdf
```

它实际调用星火、创建/清理临时账号，只核对短PDF技术通路，不包含同份Agent/完整语义核验。[26.2记录](acceptance/document-quality-20261015.md)另有本机完整复现入口及清理检查。超时先核对任务是否结束，不能删除运行中的资料；不要循环整份碰运气。

## 故障时继续演示

- 模型/网络失败：关闭自动整理，改展示已有笔记、个人补充、已有题、复习/计划和图谱；网页与数据库仍须运行，不称为完全离线。
- 无新随看笔记：检查开关、连续观看范围、完整转写片段和失败提示，不先重跑整段ASR。
- 人脸不可用：密码登录；需要本人扫描时先`npm run face:status`，必要时`npm run face:start`，摄像头本人授权操作。scan是身份比对，不是专业活体防伪。健康不代表本人登录已验。
- 登录失效：同一地址重新登录；能保存的草稿先保存/导出，不清库、改密码或来回切localhost/127.0.0.1。
- `Failed to fetch`：检查网页终端、浏览器完整地址和`npm run demo:check`，定位失败请求；不能只凭此判定余额用完。
- ModelArts停止：已有资料展示无需Ascend。新视频/图片视觉推理才按 [DEPLOY §8.5](../DEPLOY.md#85-桌面主仓库接入-modelarts-ascend-的本地演示)核对最新SSH/预热/隧道；旧端口及health快照不证明现在可用，普通demo:start不启动Notebook。
- 数据丢失：停止写入、保留现场，按备份单在新库/新目录恢复核对，不执行Prisma reset或Docker删卷。
