# §27.3 管理员分类与共享题库验收

2026-10-16，桌面主仓库。仅此编号；未实施整卷发布/学生考试/AI自主出卷或PDF/Word提取。

## 实现结果

`/admin/exam-bank` 接入管理员专属导航，科目三类别、科目/章节草稿/改名/启用/停用；分类代码和归属固定，名称与状态用updatedAt冲突保护。共享题库四类题型的增查修订、来源/年份/适用范围/使用资格、历史答案预览、人工审核、启用及停用/逻辑删除可操作。修订追加UNREVIEWED新版本，不改原正文/答案，旧版本不可删除；未审核或分类不可用禁止启用。

三个管理API：exam-subjects、exam-questions、exam-import。bank-contracts严格校验、bank-service事务授权与幂等、services/exam-bank封装客户端HTTP。PRIVATE题全部排除，管理员本人的私人AI题也不经此入口公开。公共题库素材尚非学生可见试卷，不提供正式出卷入口。

JSON/CSV自编模板可下载/填入/选文件，最多1MB、100题；CSV为difficulty/body/source固定三列、后两列JSON，支持引号/逗号/换行。预览逐行列出错误与有效题内容；分类/格式/正文变化使预览和勾选失效。确认携带原摘要、UUID及明确勾选，重新校验后全批原子写草稿，错误不跳行保存。共享管理采用现有AuditLog唯一摘要ID和事务锁防重，无新表、迁移、依赖或模型调用。
