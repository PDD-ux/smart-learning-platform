# §29.8 智能批改、错因与订正报告验收

日期：2026-10-20。范围只含§29.8，不执行§29.11。

## 结果

作业批改入口嵌入本人已确认冻结的作业详情；每批可选最多8题，逐题呈现AI建议、本人参考依据摘录、错因、下一步和独立的客观规则比对。本人明确同意后才发送所选题目和依据。订正复核追加保存订正前后答案与结果，失败/取消保留原作业和订正草稿。报告仅本人可见，不改班级正式评分、负责人评语、练习记录或掌握度；未解决建议接入既有题库/错题页分组，不创建新刷题中心。

严格选择/判断规则与AI建议分开显示。百分制必须与结论一致（正确100、错误0、部分1–99）；分数不合约、AI建议与客观规则冲突或依据缺失时转为待核验/失败，不显示伪造分数。来源短摘录须逐字命中本人冻结的参考答案或评分依据；不接受模型改写引用。

## 验收证据

- `scripts/acceptance/homework-grading.ts` 在独立临时PostgreSQL数据库执行25项检查：认证、本人范围、管理员/跨账号拒绝、明确同意、题目数量/字符预算、输入快照/请求键幂等、重复启动、取消、迟到模型响应、订正重放、错因本人范围、归档限制和正式成绩/历史数据不变。临时库已清理，`.env`与`.env.local`未改。
- 真实Spark Lite合成题回放通过：原答案A对参考答案B得到`incorrect / 0`，引文命中参考依据；订正为B得到`correct / 100`。真实分析和复核均为`READY`，`report.json`只记录结论/固定错误码/计时，不保存模型原文或密钥。完整脱敏结果位于`.taskbook-working/homework-grading-20261020/report.json`。
- 曾出现真实Lite结构不合约，包括缺少字段、额外字段、百分数类型不正确或引文不命中；这些响应均未保存为部分报告。依据讯飞官方HTTP说明调整Lite提示发送方式并缩短/澄清字段示例；上线仍保留严格校验和失败关闭。单次成功样例不代表Lite每次都稳定。
- `npx vitest run tests/unit/homework tests/unit/ai/schema-diagnostics.test.ts`：16项通过；覆盖AI/规则冲突及分数不一致降级、冻结页、同意、依据显示和订正历史。
- `npm run type-check`、§29.8相关源码ESLint、`npx prisma validate`通过。
- 本机开发库原有迁移均已完成；新增`20261020130000_homework_grading`以`npx prisma migrate deploy`应用，仅新增报告窄表和索引，没有改写原作业、班级成绩、练习或掌握度数据。

## 适用边界

演练仅使用一题合成选择题，不发送任何学生真实作业。它证明受控的一次错误答案/订正语义和数据边界，不证明各学科的广泛批改准确率，也不取代负责人正式批阅。Lite后续若输出不合约，产品应继续显示失败并允许用户明确重试，不能降级放宽schema或自动重发。
