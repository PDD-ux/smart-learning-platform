# §29.21 视频直链导入：实现与验收

时间：2026-10-21 14:37（北京时间）。桌面主仓库。实现及隔离验收已完成，真实公网下载/解析和原生浏览器点验仍待完成；未核销§29.11。

## 使用入口

打开学习中心`/import`，展开导入资料，选择“公开链接 → 视频直链”，输入直接返回MP4/WebM文件的HTTP(S)链接。确认本人使用授权与解析额度后点击“导入视频并开始解析”。下载/媒体验证完成后刷新本人资料列表并提供进入学习；解析、OCR、转写与AI笔记沿用既有流程，分别显示实际状态。网络结果不明确时重新读取状态，不会自动重发。

本轮支持100MiB、120秒下载、最长2小时的H.264 MP4和VP8/VP9/AV1 WebM。播放网页、网盘、登录资源、HLS/DASH及DRM不支持。视频本体流式落临时目录和私有对象存储，不进入数据库Bytes或整段内存；ffprobe限制本地file/pipe协议。来源SHA256和网址保存，未提供的作者/日期留空。

## 实现与保护

- 共用URL安全传输的完整DNS/IP校验、固定目标、实际socket复核、逐跳重定向与HTTPS不降级保护。文档30秒/2MiB HTML/10MiB PDF预算保持，视频独立120秒/100MiB。
- 新增`POST /api/video-imports`与前端服务/面板，复用UrlImportDraft及本人状态读取、取消、到期维护。严格`requestId/url/confirmed:true`、本人锁、请求摘要和限流；同键不重复下载/入队，异URL冲突。
- 媒体通过后VIDEO/PENDING和AsyncJob同事务保存，队列接收后内容转PARSING；入队失败保留源文件、标FAILED，使用原资料重试入口。入队前进程退出仍保留PENDING，可显式complete重试。没有后台定时恢复或新持久化队列承诺。
- 取消、过期、失败和账号删除后的迟到对象清理只针对本草稿；正式视频保留。未知/失效本机编号可清除，切换账户后不会困在不可读编号中。原文章/PDF流程及已有笔记保持。

## 复现

1. 本机现有PostgreSQL、ffmpeg/ffprobe与本地存储按现有配置可用。
2. `npx vitest run tests/unit/url-imports tests/integration/content-import-flow.test.ts tests/unit/api/content-resource.test.ts`。
3. `npx vitest run --config scripts/acceptance/video-url-vitest.config.mts`：创建并清理隔离账号；真实公网项保持原保护，结果单列。不会消耗OCR/ASR/AI额度。
4. 启动本地网页后运行`npx tsx scripts/acceptance/video-url-http.ts`：仅安全/隔离HTTP，不导入外网媒体或触发模型。
5. DNS恢复真实公网解析后，从页面明确确认导入有授权的直链并验收播放/笔记；这一步会启动配置的真实解析服务，当前未通过。
