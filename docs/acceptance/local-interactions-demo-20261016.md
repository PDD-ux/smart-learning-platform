## 演示入口

- 虚构课程：演示课程：错题复盘的三步法（虚构）
- 课程 ID：`8093dd77-ff72-4f48-ac80-092fe7498cd5`
- 页面：<http://127.0.0.1:3100/courses/8093dd77-ff72-4f48-ac80-092fe7498cd5>
- 演示网页只绑定 `127.0.0.1:3100`，发布环境开关仅对子进程生效；原 `127.0.0.1:3000` 服务保持运行且未改动。

启动或重建演示课程前，先在主仓库目录执行：

```powershell
npx tsx scripts/demo/local-interaction-course.ts seed
node scripts/demo/start-local-interactions.cjs
```

启动服务的终端保持运行。用自己的学习者账号登录演示网页后，打开课程讨论。第二个学习者账号可从另一个浏览器会话登录。自动化真实HTTP验收命令为：

```powershell
npx tsx scripts/demo/accept-local-interactions.ts
```

结束展示后，下架课程并关闭讨论：

```powershell
npx tsx scripts/demo/local-interaction-course.ts withdraw
```

然后在启动服务的终端按 `Ctrl+C`。启动器检查本机数据库、local对象存储和端口，只监听回环地址；不会终止占用端口的其他进程。退出时会校验并清理它创建的系统临时构建目录。

## 验收结果

双学习者通过本机真实HTTP登录与接口完成以下流程：

1. 学习者甲和乙能在共享课程列表看见这门已发布课程。
2. 甲建立讨论主题，乙能读取主题并提交回复。
3. 甲收到一条未读回复通知，通知带有该主题的回看地址。
4. 乙的参与记录包含该课程主题；乙不会收到自己的回复通知。
5. 自动化流程结束后，两个一次性账号、主题、回复和通知均已清理。

验收输出：`status=passed`，六项流程检查通过，`temporaryAccounts=2`，`temporaryDataRemoved=true`。课程状态为 `PUBLISHED`、讨论开启、发布授权标记为真；来源资料已从课程解除并清理，课程仅使用原创虚构Markdown内容。最终本机数据库保留一门该虚构共享课程，讨论主题、回复、通知、临时来源资料及临时学习者均为零。原有三名学习者与管理员角色数未变化；端口3000、配置与用户资料未改动。

`npm run type-check`、`npm run lint` 和启动器 `node --check` 均通过。此次通过的是服务端真实HTTP交互验收；没有完成浏览器视觉检查，不能据此宣称页面视觉或整个项目所有功能均无问题。
