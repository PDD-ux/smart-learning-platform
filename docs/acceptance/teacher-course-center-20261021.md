# §29.19 教师课程中心验收记录

日期：2026-10-21。范围仅为已确认的教师端课程优先呈现，未开始§29.11。

## 结果

- `/teacher`首屏先展示本人课程卡片：课程名称、状态、有效学生、任务及待批阅数，以及“进入课程空间”；空列表提供建课入口。错误仍显示重试，加载期间不显示虚假计数。
- 教师导航中的“我的班级”改为“我的课程”，“授权课程资料”改为“课程资料”。课程详情默认进入“课程概览”，可切换到课程章节、学习任务、学生与设置；章节/任务/成员/邀请码/编辑归档继续走原工作流。
- 概览复用已读取的ClassDetail，仅显示有效成员、章节和任务数量，并说明任务数包含草稿。没有新增课程实体、表、迁移、接口、DTO、依赖或权限规则；学生端与管理员旧班级兼容流程不变。

## 验证与限制

`npm run type-check`、`npm run lint`、`npm run build`通过，构建输出既有BullMQ可选`@valkey/valkey-glide`未安装警告。新增`tests/e2e/teacher-course-center.test.tsx`中的2项页面交互测试通过，覆盖真实总览数据投影、课程空间链接、课程概览默认页和章节页签切换。

全量`npm test`共192个测试文件、1740项：184个文件/1726项通过，8个文件/14项失败。失败文件为`admin-center-pages`、`app-shell-states`、`learner-main-path`、`session-page`、`shared-courses`、`auth-phone`、`live-notes-retired-routes`和`exams/retired-routes`；包括旧教师登录测试仍期待`/classes`、学习者页面测试停在加载态、共享课程测试仍期待管理员发布表单，以及2项退休路由测试超时。这些文件不在本项改动范围；本记录保留结果，不据此擅自扩展本编号。
