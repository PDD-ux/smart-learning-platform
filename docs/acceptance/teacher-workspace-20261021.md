# §29.18 教师工作区与管理员功能分离验收记录

日期：2026-10-21（北京时间）  
范围：仅执行 `spec/05-TASKS.md` §29.18，不提前执行§29.11整链演练。

## 实现结果

- 教师登录进入 `/teacher`，独立导航提供教学总览、我的班级、作业批阅、授权课程资料；新增教师总览 API `GET /api/teacher/overview`。
- 总览服务端按当前数据库 `teacher` 角色和 `Classroom.responsibleId` 取数，只返回本人班级、有效成员计数、任务摘要与正式待批阅数，不返回作业正文、附件、评语或草稿。API 经认证并设置私有不缓存响应。
- 教师端复用现有班级、作业、提交、附件和批阅工作流组件，路由与操作链接保持 `/teacher` 前缀。管理员侧栏移除教学发布入口，旧管理员班级明确标为兼容入口；管理员共享课程页面仅对已发布副本提供治理/下架。
- 学生学习入口和人脸登录/打卡没有迁移。教师总览实现加载失败/重试、真实空态；班级表单沿用草稿保留逻辑，窄屏导航/内容布局已实现。
- 当前主库只读检查为班级0、正式批阅0；所以本轮无旧班级可移交，未改班级、成绩、附件或负责人。

## 工程验证

- `npm run type-check`：通过。
- `npm run lint`：通过。
- `npm run build`：通过，路由清单包含教师工作区页面及 `/api/teacher/overview`。构建仍打印既有BullMQ可选`@valkey/valkey-glide`解析告警；不影响本次构建成功状态。
- 未新增数据库表、迁移或运行依赖。

## 未覆盖项

当前本地 `127.0.0.1:3000` 没有运行服务，原生浏览器打开 `/teacher` 收到 `net::ERR_CONNECTION_REFUSED`。本轮因此没有真人操作教师总览、桌面/手机宽窄屏、无权角色直达URL或实际教师批阅页面；代码构建不等于这些页面验收。按任务顺序留至§29.11，用管理员、教师和两名学生做真实浏览器整链验证。教师角色后端隔离证据见[§29.17验收记录](teacher-role-20261021.md)。
