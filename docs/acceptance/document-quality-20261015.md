# §26.2 文档知识点与回忆卡质量验收

完成：2026-10-15 16:40，北京时间，桌面主仓库。只处理26.1的短文档空泛、重复和引用支撑问题，先落spec/14-DOCUMENT-QUALITY.md再实现。全程使用当前星火，没有调用百炼、训练模型、自动公开或重写原资料。

## 实现

文档原来源经完整性/页码校验，整块封面/目录先识别再分批，避免目录后半段丢标题后变成正文。服务器按换行及中文句末标点生成连续事实候选，过滤独立网站页眉和没有正文的编号标题。模型仅返回单行事实F编号，不写标题、摘要或引用。服务器恢复原文片段、冒号前主体或原文前24字标题，refs只对应实际支持摘要的来源；未知、重复编号及无实际原文均拒绝。归一化仅处理兼容字形/空白，存储原始文字，不改数字，不用特定课程结论黑名单。

文档复习卡收敛为原文回忆：按现有知识点refs重新读取实际TextBlock，核对原文摘要和主体，生成明确含主体的题面及原文答案。最多700字、不截断补造、不接受历史空泛摘要或错页引用；不额外调用模型改写卡片。保留Flashcard/SM-2/自评、原生成笔记格式与视频AI卡片路径，不冒充语义判分或全课概念讲解。

主要代码：src/lib/jobs/pipeline/document-quality.ts、document-extraction.ts、deep-extract.stage.ts、product-gen.stage.ts；对应四个jobs测试文件。没有公开字段/接口、表、依赖或页面布局变更。

## 真实迭代与最终结果

本轮四次隔离导入分别针对不同实现，不是同版本循环试成功：

1. real：要求模型逐字摘要，两次格式/原文校验失败，队列按既有策略重试后整体失败，约110秒；未进入卡片成功态，旧真实资料不变。
2. real-selected：改为服务器事实编号选择后能生成有据知识点，但模型卡片三行格式失败，约161秒；保留失败证据。
3. real-final：文档卡改为服务端原文回忆，技术通过、约34秒；人工发现页眉和空章节标题也被模型选成事实，明确未核销质量。补结构候选过滤。
4. real-verified：最终同一独立三页PDF经真实登录、上传、解析、理解及同份Agent API约32.956秒，READY/COMPLETED、两任务成功。3文本块、4知识点、4回忆卡和AI笔记，原资源字节一致，匿名理解401。

最终四点为副省级、市地级、重庆、青海对应的原文公式/比例；所有refs都在实际第3页，逐项与原PDF文字和既有渲染核对，原字与数字一致。没有“命题趋势”等无据扩写，也没有网站页眉/章节空标题；回忆题绑定实际对象、答案含具体公式，4个问题及原文事实不重复。重庆和青海比例相同但对象不同，不误合并。抽取4点不代表整页或整课全覆盖。

Agent约9.709秒、HTTP200，仍为已有安全证据模式，没有启用未核验的自由解释。未代答、未保存方案、不查模型余额。Agent不作为本项扩展功能。

verification.json将原文字面支持、卡片答案及清理逐项自动核对；本样本人工事实/引用/信息量核对通过。旧run入口的report.json故意保留semanticAccuracyAccepted=false通用初值，不把它改成全材料准确性保证；完整结论以real-verified的实际产物、verification.json及本记录为准，不能只引用第三轮技术passed。
