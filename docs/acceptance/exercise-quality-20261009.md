# 出题约束与错题闭环复验（2026-10-09）

本轮只继续 §10.2，在桌面主仓库修复此前真实验收发现的题干条件不足，并加强题库闭环的验收证据。没有新增功能、页面、接口、数据库字段或依赖，没有改写既有题目或其他用户资料。

## 最终修改

出题提示采用完整合法 JSON 示例，要求明确题干条件，参数增减问题交代改变对象和固定量，优先使用定义、公式与明确算例；干扰项必须在条件下错误，禁止等价答案，不能保证唯一答案时换题。模型在内部自查，解析说明依据；不返回额外自检字段。

服务端验证返回题数严格等于请求 count，不再切片掩盖数量不符；同批去首尾空白/小写归一化题干禁止重复。题干、选项、标准答案与解析去首尾空白后不能为空。已有选项不重复、标准答案必须命中选项、判断题规范格式、内容安全与一次校验修正重试保留，失败仍明确 503。

验收入口改为日期/runId 独立文件；在隔离账号本轮生成题目中读取标准答案，选择非标准选项并断言判错，再验证 wrong/unanswered 筛选和重练最新记录。保存所有题目的标准答案与解析，便于人工核对。客户端超时调整至 150 秒以覆盖两次各 60 秒的后端尝试；产品网关超时不变。

独立精简诊断依然出现四个选项只有两条自检、漏 type 和自检判断错位，见 [中间诊断](exercise-quality-diagnostic-20261009.json)。最终取消额外字段，保持较短提示；这些中间输出不算通过，也没有持久化到产品题库。

最终实际运行时间为北京时间 08:52:20–08:53:09，退出码 0，见 [最终完整原始记录](real-ai-flow-20261009-a290c048-362f-4c5d-b0ad-66ca1bad8356.json)。真实讲义上传与解析后生成 3 个知识点、3 张闪卡，问答正常。真实题目人工核对如下：

- “梯度下降用于最小化损失函数时，更新参数的方向是？”标准答案“沿负梯度方向”，符合讲义。错误选项中“沿梯度方向”和“沿正梯度方向”含义接近，干扰项多样性仍一般；没有多个正确答案。
- “对函数 f(x)=x²，x=3、学习率 0.1 时，下一步 x=？”标准答案 2.4；计算为 3−0.1×6=2.4，与原文一致，其他数值均不满足本题计算。两题解析说明正确依据，但没有充分逐项展开干扰项原因。

第一题明确选错误项，接口 correct=false；错题筛选 total=1。按返回标准答案重练 correct=true，历史曾错题仍 total=1，最新记录为正确；未作答筛选剩 1 题。题库总数为 2，闪卡复习与掌握度/图谱回读通过。错题筛选语义仍为“历史曾答错”，不是重练正确就删除。

两轮临时账号、独立上传对象和关联记录均已清理，cleaned=true。未执行真实 Ascend/ASR 推理，不覆盖完整长视频或生产环境验收。
