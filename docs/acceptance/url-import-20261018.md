完成时间：2026-10-18 20:55。本轮只实施29.14，未实施29.15、班级作业或智能批改。大模型、ASR、MindSpore及人脸配置未改，没有模型调用或训练。

## 使用与实际结果

学习中心 `/import` 右侧“导入资料”选择“公开链接”，输入公开文章/直接PDF地址，先“获取预览”，核对来源/正文并勾选确认，再“保存到我的资料”。重复内容可复用已有资料，也可明确另存副本。进入学习后可选段提取、阅读及使用原个人笔记流程；快照不自动刷新，尚未章节AI整理。

真实公网探测：中文MDN JavaScript介绍获取228891字节，净化后76段、14目录项，预览前20段793字；W3C dummy.pdf获取13264字节、1页、文本层14字。原始/保存内容SHA分别记录，不捏造作者和发布日期。使用原生浏览器实际完成MDN预览、勾选保存、打开来源卡与提取前20段；没有将预览或局部提取称为全书理解。

手机390px实际client/scrollWidth均382px，导入输入框256px、可见按钮44px，学习页使用已有compactNavigation的64px图标栏。验收发现原学习页未启用该选项导致210px侧栏挤压，此次补上；桌面保持原导航。截图：`.taskbook-working/url-import-20261018/import-mobile.png`、`study-mobile.png`、`study-desktop.png`，结构化结果`browser.json`。临时浏览器资料已精确清理，不保留为用户课程。

## 明确限制与保留失败

支持公开静态HTML和直接PDF；已知视频/网盘入口拒绝，动态/登录或正文不足页可能无法提取，应改用本人有权使用的文件。无需也不会执行网页脚本、加载图片/子资源或转交浏览器Cookie；不承诺任意站点正文提取质量，MDN仍有少量正文区域内的翻译提示/上一页等文字。复杂数学/图片不是HTML正文识别能力。

HTML2MiB、PDF10MiB、全获取30秒、最多3跳、正文10万字/5万节点/64层；PDF解析沿用既有每次30秒与2000页限制。每用户6次新获取/分钟、3份待确认、30分钟过期。过期维护为本人访问时触发及有界CLI（每次最多100份），未安装定时任务；网络失败需用户显式新预览。原快照/旧引用不会自动更新。

保留初次验收脚本缺少临时密码哈希和.env优先级不一致导致的失败日志；修复的是验收夹具，没有修改真实账号。也有一次公网预览未就绪的未完成回放，未保存资料；未记录原网络异常正文，不推断具体站点原因。随后30项与最终38项完整回放通过，不能据此保证公网永不波动。最初合并启动/写脚本命令被自动审批拒绝，拆成独立操作后完成，没有跳过保护。

Windows生成Prisma客户端曾因运行中的DLL占用失败，核对并停本仓库网页后生成，再隐藏重启127.0.0.1:3000；当前本地网页已恢复。未验生产反向代理/真实OBS并发或崩溃恢复、全部站点/PDF兼容性；下一编号29.15仍待执行。
