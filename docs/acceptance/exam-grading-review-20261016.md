4. 管理界面原先默认所有未评题0分、提交全部主观题、固定请求键、最终冻结后仍提示可修订。现在分数初始空白、已评保留原值，只提交显式修改项；失败保留输入，相同内容重试原键、改内容新键，写入锁定编辑/读取，成功同步revision；最终冻结禁用。
