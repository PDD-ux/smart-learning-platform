## 复跑

在主仓库先执行 `npx prisma generate`、`npx prisma migrate deploy`，再启动 `npm run dev`。另一个终端执行：

```powershell
npx tsx scripts/acceptance/study-plans-bank.ts
npm run test
npm run type-check
npm run lint
```

可用 ACCEPTANCE_BASE_URL 指向同一主仓库环境文件和数据库对应的本地服务。脚本创建两个带随机密码的临时账号并实际登录，令牌仅存在内存，不写文件或日志。仅应对自己管理的本地测试数据库运行；异常退出时 finally 尽力清理。

## 演示路径

1. 登录已有账号，打开学习中心，导入资料或选已有就绪资料进入学习；学习页可返回中心。
2. AI 学习助手选择已理解完成资料提问，检查引用并跳转时间点/页码。
3. 学习计划选择资料、填写目标分钟和时间；设置已到期提醒，工作台查看提醒与完成进度，然后标记完成/撤销。
4. 题库选择已理解完成资料并生成题目，查看选项并提交；再切换未作答或曾经答错，选择题目重新练习。上次作答的解析可展开查看。

## 已知边界

- 提醒仅是登录后工作台每分钟刷新的站内提醒，不会在关闭网页时推送。

- 简答沿用规范化字符串匹配，不是大模型语义评分；曾经答错包含历史错过而后来已答对的题。
