# 实时课堂笔记使用说明

登录学习者账号后打开 http://127.0.0.1:3000/live-notes，或点击侧栏“实时课堂笔记”。填写标题，点击开始录音，在浏览器亲自允许麦克风。约每5秒出现一段转写；开启自动整理后，每6段生成一次重点。可以暂停、继续，最后点击结束整理，查看完整转写及重点并导出Markdown。

这是麦克风录制课堂/会议的独立入口，原视频导入与分析仍保留。不是逐字即时字幕，不包含说话人分离或会议软件接入。单次最多30分钟，识别文字及AI辅助标题需要人工核对，来源正文为实际ASR文本。

本地转写不消耗云ASR额度，不需要打开Ascend。AI重点仍调用现有星火，可能受额度、超时或审核限制。取消自动整理可以只转写；最终Markdown整理全量已保存文本，不额外调用AI。

失败时页面自动暂停，请保留当前页面，按提示手动重试同一片段；不要刷新，未发送音频仅存在当前内存。若不再重试，可以确认仅保存成功转写，笔记会明确标注不完整。录音期间离开页面会释放麦克风。历史未结束记录可以重新授权接着录制；刷新不会恢复未上传录音。服务异常中断需等待约2分钟租约恢复后重新读取/尝试结束。

当前已验证真实30秒文件分片的本地ASR、星火重点、持久化/权限和页面读回、导出；真人麦克风、实际硬件权限与30分钟连续录制仍需本人试录。先录30—60秒，暂停再继续，结束后核对文字、来源及下载结果，不要把接口测试当作真人验收。

部署配置参见DEPLOY.md §23.1。可复现真实接口入口：`npx tsx scripts/acceptance/live-notes.ts .taskbook-working/live-notes-repeat`（新目录，需已有样例WAV、本地模型、数据库、3000服务和有效星火配置；会调用一次实际模型，临时账号最终清理）。生产资源验证：`node scripts/acceptance/production-demo-smoke.cjs --output-dir .taskbook-working/live-notes-production-repeat`，不调用真实麦克风或模型。
