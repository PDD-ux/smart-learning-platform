# §28.2 华为云学习语言模型LoRA实验

用户已选择华为云，并于2026-10-18要求继续。该实验是独立训练准备，不替换已实现的OpenAI主用/星火备用网关；不更改MindSpore视觉或ASR，不读取私人课程、讨论、笔记或考试记录作为训练数据。

## 本编号交付

1. 单卡Ascend 910B4 32GB；复用MindSpore2.7.1、MindFormers1.7.0，遵守其r1.7.0源码，不能套用master/2.0动态图训练指导或8卡/58GB默认配置。
2. 先选Qwen/Qwen2.5-1.5B-Instruct作通路试训候选，不称其强于现有商用模型。这是开源权重，不调用百炼或阿里云API。固定仓库revision、Apache-2.0许可元数据及官方配置SHA-256。
3. 原创短课堂来源与明确不足样本，仅用于格式/流程冒烟；train与heldout按来源组拆分，不复制私人学习资料。训练目标先为带逐字引用的原文要点，不将微调声称为新增知识事实核验能力。
4. 校验器拒绝重复ID、跨集合来源组或正文重叠、无真实原文引用、空输出、非法结构；对不足样本要求空要点和明确needs_more_context。输出兼容官方messages JSONL，heldout不进入训练文件。
5. 生成器从固定官方配置校验哈希后缩小为单卡、1024上下文、batch1、LoRA rank8及24GB设备预算；配置仅为待实测候选，未取得tokenizer/权重时不称可训练。必须在真正预处理前检查完整对话token长度，不能让官方默认truncation默默截掉答案。
6. 只允许版本/空间/NPU检查，以及随机微型Llama的LoRA前向/梯度/参数冻结验证；严格时限与独立目录，日志不写凭据，随机权重不当成训练后的课堂模型。无安装/下载模型/完整微调/HTTP部署隐式副作用。

代码位于services/learning-lora，不进入Next打包或现有推理服务。Python标准库负责数据校验/固定源码校验；云端配置生成依赖现有PyYAML，运行检查依赖已安装MindSpore/MindFormers。无新npm依赖或数据库迁移。

大模型基础文件、编译缓存放独立临时目录；/home/ma-user/work仅剩约3.5GiB，不能直接堆放基础权重或多份全参检查点。其它目录空闲不等于可跨停止保留；未来训练成果必须持久保存并导回本机校验，再考虑删除临时缓存。当前不扩容磁盘、不改变实例规格、不启停实例。
