## 1. 项目一句话说明

**把任意视频 / 图文 / 拍照笔记等学习资料，通过「端云协同」AI 一键转成可复习的知识卡片、练习题与薄弱点地图，帮助学习者完成「学 → 练 → 测 → 看」的闭环。**

---

## 2. 项目目标

| 编号 | 目标 | 说明 |
|------|------|------|
| G1 | **内容结构化理解** | 对上传的视频 / 图文内容，自动抽取知识点、生成笔记 / 闪卡 / 知识图谱 |
| G2 | **端云协同技术落地** | 用 MindSpore 承担端侧课堂关键帧三分类（板书 / 屏幕教学内容 / 无效帧）与文字区域检测；屏幕教学内容涵盖 PPT、PDF、代码及软件演示，不按学科分类；ASR 提供带时间戳的语音文本；大模型融合两类证据生成可追溯、可编辑的课堂笔记 |
| G3 | **复习练习闭环** | 基于闪卡（SM-2 遗忘曲线）+ AI 出题练习 + 掌握度评分，形成「学后必练、练后知弱、弱后补强」的闭环 |
| G4 | **薄弱点可视化** | 通过知识图谱 + 掌握度画像，让学习者一眼看清自己哪里弱 |
| G5 | **可追溯学习资产** | 学习者的导入资料、AI 整理笔记、个人补充、闪卡和练习记录相互关联且彼此隔离 |

## 4. 核心使用场景

### 场景 1：导入内容，自动解析（主线）
1. 学习者上传本人拥有或获授权的一段网课录屏视频（或 PDF / Markdown 课件、拍照资料）。
2. 系统后台异步解析：**MindSpore 每 2～5 秒分析一帧，判为板书、屏幕教学内容或无效帧**；PPT、PDF、代码及软件演示同属屏幕教学内容，无效帧不进入 OCR 与大模型。保留帧的 OCR 文本与 ASR 时间戳转写共同交给云端大模型做深度理解。
3. 上传者在上传页**实时看到解析进度条**（抽帧、关键帧识别、OCR、ASR、AI 整理）。
4. 解析完成后，进入学习页即可看到：带时间点的 AI 整理笔记、转写文本、知识点与自动生成的闪卡；学习者可以保留自己的实时笔记并编辑 AI 笔记。

### 场景 2：边看边记笔记
1. 已上传视频提前解析后，学习页默认显示“播放同步笔记”：按已解析知识点的真实时间引用切换重点，同时显示当前位置的转写原文；支持查看全部重点、点击时间回看及独立保存个人补充。没有时间引用时明确提示，禁止猜测定位。初版为预解析展示；2026-10-13用户进一步澄清，需要播放时按实际看过的转写逐段调用AI生成笔记。
2. 学习者在学习页播放视频，看到某处重点，随手创建一条笔记。
3. 笔记自动绑定视频时间戳（或文档页码）。
4. 之后点击任意笔记，可跳转回对应播放位置 / 文档段落。
5. 多设备同时编辑时，系统提示「内容已在其他设备更新」并同步最新版本。

### 场景 3：复习闪卡，对抗遗忘
1. 学习者进入复习页，系统按遗忘曲线（SM-2）推送「今天该复习」的闪卡。
2. 学习者对每张卡评分（忘记 / 模糊 / 犹豫 / 记住），系统据此调整下次复习时间。
3. 反复复习后，掌握度提升，卡片进入「已掌握」。

### 场景 4：AI 出题练习，查漏补缺
1. 系统识别出学习者的薄弱知识点。
2. 学习者发起「练习」，AI 根据薄弱点自动生成选择题 / 判断题 / 简答题。
3. 作答后立即判分，展示解析，并回写掌握度。
4. 薄弱点地图随之更新。

Phase27新增整卷路径：用户选科目/考试范围或本人资料，设置题量、题型、难度、分值及时间；可选已审核题库自动组卷，或让AI拟定蓝图、自主选择可用题并在显式允许时编写模拟题。预览真实题量和来源后进入答题卡、计时续答、交卷、成绩与错题回看。AI不足或质量失败时保留未完成草稿，不重复或编造题凑满；个人AI模拟明确待核验，正式发布需管理员审核和来源确认。该路径已按27.2–27.9逐步实现，原零散练习及历史记录保留；真实AI整卷质量与授权新版题源仍待后续独立验收。

### 场景 5：查看知识图谱，发现薄弱点
1. 学习者打开看板，看到以知识点为节点的知识图谱。
2. 节点大小 / 颜色反映掌握度，薄弱点高亮。
3. 点击薄弱点，可跳转到对应复习内容 / 练习入口。

### 场景 6：知识问答（内容内上下文）
1. 学习者就当前学习内容提问（例如「这个定理的适用条件是什么」）。
2. AI 基于该内容的解析结果回答，并给出引用出处（转写段落 / 知识点 / 原文定位）。

### 场景 7：AI 学习助手
1. 学习者从独立的 AI 学习助手入口选择一份本人已完成解析的资料。
2. 学习者围绕所选资料连续提问，AI 仅依据该资料回答，并给出可返回学习页核对的引用出处。
3. 切换资料后清空本页问答记录；问答记录只保留在当前页面会话，不写入持久化存储。

2026-10-10 用户在了解无需先训练模型后明确要求“做一个比较强的agent”，确认扩展现有助手为受控学习Agent（§21.1）：学习者选择本人已解析资料、可用时间并提出目标；大模型自主选择读取真实学习状态、检索原文及挑选已有练习的工具，多步读取工具结果后给出带出处的解释、时间预算内的复习步骤和可直接作答的练习。没有学习记录时说明暂无诊断依据，不把未学习等同于已证明薄弱。作答沿用真实判分及掌握度，学习者可再次请求分析最新记录。复习方案先预览，点击保存后才进入既有学习计划，不自动完成计划或发放XP。保留资料问答模式及页面会话隔离；不训练新模型、不新增开放浏览器/系统执行、后台自主代理、跨用户或跨资料访问。

## 7. 验收标准

### 7.1 功能验收（P0 必达）

1. **内容解析**：上传一段课堂视频 → 解析完成 → 学习页可见转写文本、关键帧依据、AI 整理笔记、知识点列表与自动生成的闪卡。
2. **端侧关键帧理解**：MindSpore 对视频帧完成**三类课堂关键帧分类**（板书 / 屏幕教学内容 / 无效帧）与文字区域检测；无效帧不进入 OCR/AI。MindSpore OCR 在 CPU 上不可用时应转到 Tesseract 中文/英文识别；未安装 Tesseract 时才安全降级为空 OCR 结果。
3. **知识抽取**：大模型抽取知识点并生成闪卡，构建知识图谱。
4. **实时笔记**：学习页可创建带时间戳的笔记，点击笔记跳转对应播放位置。
5. **复习闭环**：闪卡按 SM-2 排期复习，评分后下次复习时间正确变化；掌握度随复习 / 练习更新；薄弱点看板正确展示。
6. **账号与隔离**：注册 / 登录可用；不同学习者的笔记 / 闪卡 / 练习记录互不串扰，底层知识点可复用。
7. **主路径贯通**：学习者完整走通「导入 → 解析 → 记笔记 → 复习闪卡 → 薄弱点发现 → 图谱查看 → 知识问答」，各页面跳转与状态同步正确。
8. **管理员用户管理（P1）**：管理员可在 `/admin/users` 查询、新增、编辑和删除用户；普通用户访问返回 403；管理员不能删除自己的账号。
9. **管理员管理总览（P1）**：管理员登录进入 `/admin`；总览及 `/admin/users`、`/admin/attendance` 共用只含管理入口的专属导航，显示当前管理员昵称并可手动刷新概况；账号角色计数、今日签到计数及最近账号来自真实数据库；普通用户页面和接口均被拒绝；签到只汇总结论，不展示人脸或学习者私有内容。
10. **人脸签到（P1）**：学习者明确授权后可完成特征录入，所配置的人脸验证模式通过后登录并每日自动打卡；密码登录后普通打卡无需审批；数据库不存照片二进制，仅保留加密照片的私有对象键与 30 天到期时间，删除模板后立即失效；管理员只能查询签到结果。
11. **长视频处理（P0）**：用户于2026-10-10明确本次仅为毕设演练，采用已有30分钟课堂视频及其真实预解析转写/OCR，检查分窗重点及后半段引用、笔记定位/续播/媒体读取，符合“提前解析、播放时同步展示”的既定方案。更长视频能力保留，但2小时46分钟及46分钟样例不作为本次演练门槛；重新导入、ASR/Ascend稳定性及历史失败独立保留，不能用已解析资料演练通过代替完整重新导入或生产验收。
