## 2. 书籍导入和阅读流程

1. 上传有权使用的PDF/TXT/Markdown书籍，EPUB单独实施和验收；预览书名、实际格式、可提取范围、页数/章节及异常。作者/出版信息只有原文件明确提供或本人填写才保存，不根据文件名猜ISBN、版次或年份。
2. 优先读取真实PDF目录/EPUB导航及阅读顺序；文本标题识别须可校对。没有可靠目录时按页段阅读或由用户手动分章，标明本人目录，不把自动分段当成书籍原目录。
3. 用户选择本次章节或页段，后台分段提取并保存实际范围。长书可以先读/整理一章，后续继续；阅读、文字提取、AI整理各有独立状态，不能将3页样例完成标成整本完成。
4. 阅读器显示目录、正文、书签、阅读位置、摘录/高亮和个人批注，AI章节笔记在旁或内部切换；窄屏顺序为正文→笔记，长标题/原文不挤占阅读宽度。切章保留已保存位置和独立草稿。
5. PDF引用用实际文件页码，印刷页码只有已知映射时另标；EPUB用章节/段落稳定位置，不虚构固定页数。来源引用绑定内容版本，更新或重新分章不能把旧摘录悄悄指向新内容。
6. 扫描书籍的选定页进入OCR，显示无法识别页及校对入口；公式/图表不可靠时保留原图/页位置并提示缺失，不以空文字或AI补写冒充识别成功。

首版不支持MOBI/AZW、受DRM保护或加密文档解锁，不承诺全部排版/复杂公式。EPUB需先验证真实格式、安全解包、目录/阅读顺序与正文清理；不执行书内脚本或自动访问外部资源。依据：[W3C EPUB 3.3](https://www.w3.org/TR/epub-33/)。

## 3. URL导入流程

1. 粘贴HTTP(S)公开文章或直接PDF地址，系统先检查可访问性、真实内容类型与大小；抓取/预览由后端受控执行，前端不直接获取第三方正文或厂商凭据。
2. 预览真实标题、原网址/最终来源、作者/发布日期（仅存在时）、正文片段与提取范围；用户确认后才建入正式资料。导航/广告/登录文案不能被当作文章正文。
3. 公开HTML先提取静态正文和标题结构；直接PDF走同一PDF书籍/文档流程，不复制另一套阅读器。无法提取正文时说明失败，可改选上传文件或粘贴正文；“仅保存链接”只有本人明确选择时才作为未解析书签，不计入可问答/笔记就绪资料。
4. 保存实际导入时间和当次正文快照/版本，发布日期与导入时间分开。原站变化后按显式刷新产生新版本，旧笔记仍指原快照；相同内容导入时给出已有资料/另存版本选择，不以同名误删不同资料。
5. 普通网盘分享页、B站/网课播放页面、动态登录页面和付费内容不默认支持解析，不自动传用户Cookie、密码或绕过访问限制。首轮不做全站抓取、自动跟踪更新、搜索引擎或跨网页自主Agent。
6. Windows本机路径与file://不作为服务端URL抓取：从浏览器选择本地文件上传；网页不能仅凭C盘路径读取用户电脑文件。

实现前须在03/04落地请求大小/时间/重定向预算、允许类型、取消/失败幂等和私有资源生命周期。SSRF防护必须验证DNS解析/IPv4/IPv6、实际连接目标和每次跳转，拒绝环回、私网、链路本地/云元数据及非HTTP(S)/含凭据地址，不允许靠重定向或解析变化绕过；流式下载和解压均设上限，网页脚本/事件/危险链接不得执行。URL中的敏感查询串不进入日志。依据：[OWASP SSRF Prevention](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)。

## 4. 智能笔记与资料问答

- **章节笔记**：用户选择范围后生成该章的摘要/要点和有出处摘录，可补个人理解；长书按章积累为读书笔记，显示实际完成章节/页段及遗漏，不用一次无界模型请求处理整书。
- **摘录和批注**：原文摘录与个人文字分开保存，绑定真实页/章/段落；可以按书籍/专题/标签检索，引用可回看，来源被删除或版本不可读时明确提示，不能借别人的相似内容补位。
- **资料问答**：清楚选择“当前章、该资料已解析范围、本人所选专题”，检索可用来源并展示依据；未解析范围/不足来源明确说明，不声称已经读完整本书或自动联网补知识。
- **专题学习**：把本人明确选择的视频、书籍、文章放入一个专题；专题内问答/笔记汇总逐项标来源，区分不同作者/版本的说法，不抹平冲突或把所有私人资料默认纳入模型上下文。专题不自动共享到班级。
- **整理与导出**：保留AI建议和个人笔记边界；按资料/章/专题导出Markdown/TXT，带来源及实际覆盖范围。用户修改个人笔记不覆盖原始提取内容，失败或重新解析不清掉已有批注。
