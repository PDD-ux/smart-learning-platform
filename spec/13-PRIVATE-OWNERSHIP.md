# §25.10 私人资产权限修订

2026-10-15。此契约修正公共归属校验器的历史管理员豁免，不新增功能或数据表。

私人资料、原文件、解析结果、笔记、练习和复习资产，读写均以数据库实际 ownerId 与当前用户 id 一致为准。role=admin 不提供私人资源访问豁免。管理员用户、签到、共享发布、讨论管理继续使用各自明确的管理接口；共享发布依然只能选择管理员本人持有的私人源资料。

批量归属校验同样不按角色跳过；缺失用户标识时失败关闭。跨归属校验失败返回 FORBIDDEN(403)，不透传资源所有者内部 ID。原本按本人过滤查询的列表、计划等保留既有空列表或 404 契约。鉴权必须先于签发资源链接、调用模型及业务写入。

不修改现存学习数据、角色、密码和配置，不追溯撤销已签发链接（其有效期仍由既有签名契约控制）。此项完成后另轮执行 §25.9 完整复验；正式交流门控保持关闭。
